SYSTEM ARCHITECTURE SUMMARY
================================================================================

Phase 1: Memo Creation
- HR Leave Office selects HR Executive signer
- System validates signer role
- Retrieves signer's signature (3-tier lookup)
- Creates memo with assigned_signers array
- Status set to "ready_for_review"

Phase 2: Pending Queue
- HR Executive views pending memos
- Only memos with their user_id in assigned_signers array appear
- Critical filtering prevents unauthorized access

Phase 3: Approval
- HR Executive approves memo
- System captures authenticated user (logged-in person)
- Their signature retrieved and included
- Memo status changed to "reviewed_by_hr"
- Removed from pending queue

Phase 4: PDF Rendering
- Signature from database included in PDF
- Shows approver's name and signature
- Complete audit trail maintained
