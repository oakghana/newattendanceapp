# HR Leave Office - Quick Reference Card

## 🎯 Your Main Task
**Assign pending deferment and recall requests to HR executives for approval**

---

## 📍 Where to Find It
```
Dashboard → Leave Management → Processing Requests (indigo tab)
```

---

## 🚀 Quick Steps (30 seconds)

1. **See** pending requests on dashboard
2. **Click** "Assign" button on any request
3. **Select** HR Executive from dropdown
4. **Click** "Assign & Forward"
5. **Done!** Request moves to their queue

---

## 📊 What You'll See

### Stat Cards (Top)
- **Total Pending**: All requests waiting for assignment
- **Deferments**: How many deferment requests
- **Recalls**: How many recall requests

### Deferment Section (Amber)
- Staff name and ID
- Department
- Position
- Leave type
- Reason for deferment

### Recall Section (Rose/Pink)
- Staff name and ID
- Department  
- Position
- Leave type
- Reason for recall

---

## 🔍 Search & Filter

**Search by**: Staff name, Employee ID, or Department

**Filter by Type**:
- All Requests
- Deferments Only
- Recalls Only

**Reset**: Click "Reset Filters" to clear all

## 💡 Tips

1. **Search First**: Use search to find specific staff requests
2. **Choose Right Person**: Select executive from appropriate department if possible
3. **Add Notes**: Include context like "Urgent" or "Staff special case"
4. **Batch Process**: Review all requests, then assign them
5. **Refresh**: Click F5 to see updated counts after assigning

---

## ⚠️ Important Notes

- ✅ You CAN assign multiple requests to the same person
- ✅ You CAN search by any staff detail
- ✅ You MUST select an HR executive
- ❌ You CANNOT approve requests (only assign)
- ❌ You CANNOT view final memos (HR Executive sees them)

---

## 🆘 Troubleshooting

| Problem | Solution |
|---------|----------|
| No requests showing | Click "Reset Filters" or check if you're HR Leave Office role |
| Dropdown empty | Contact admin - no active HR executives available |
| Can't find staff | Use search with name or employee ID |
| Assignment failed | Try again - check internet connection |
| Can't see changes | Refresh page (F5) |
