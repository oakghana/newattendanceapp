## Common Actions

### ✅ TO SEARCH FOR A REQUEST
1. Type staff name, ID, or department in Search box
2. Results filter automatically
3. To clear: Click "Reset Filters"

### ✅ TO FILTER BY REQUEST TYPE
1. Click "Request Type" dropdown
2. Select: All, Deferments Only, or Recalls Only
3. Results update automatically

### ✅ TO ASSIGN A REQUEST
1. Find request in list
2. Click blue [Assign ➤] button
3. Modal opens
4. Select HR Executive
5. (Optional) Add notes
6. Click "Assign & Forward"
7. ✅ Success!

### ✅ TO CLOSE MODAL WITHOUT ASSIGNING
1. Click [Cancel] button
2. Modal closes
3. Request stays in list

## Tips for Efficient Work

1. **Start with search** - Find all requests from one department
2. **Group by type** - Process all deferments, then recalls
3. **Use notes** - Tell HR Executive if it's urgent
4. **Refresh often** - See new requests as they arrive
5. **Don't rush** - Take time to select the right executive
